# Windows feature coverage

**In progress. This is an audit/acceptance matrix, not a claim that every feature or every bug has been verified.** Baseline: official Zeron 0.2.119 at `dd0c36fa3ec1e269a630562179e655b1ed26f0a0`. Its executable hash matches the user's installed copy. The original installation, provider-owned credentials and existing sessions are preserved.

User decision: retain GPUI if verified targeted fixes work; a Tauri v2 replacement remains conditional, not waived if significant framework problems remain. Tauri itself documents the same legacy Acrylic movement limitation, so a framework substitution alone is not a proven remedy.

## Evidence boundaries

- [Acceptance and reuse record](windows-reliability.md) is authoritative for decisions, confirmed findings, exact revisions and pending work.
- Windows harness baseline: 316 passed. Focused candidate harness: 338 library tests and 75 integration/native tests passed in saved local logs.
- Pre-Zui-patch compiled UI binary: 1845 passed, 5 ignored, 2 filtered out. It is not the final candidate test result.
- Zui native fixes are pushed to the fork's testing branch; the main application changes have not yet been committed/pushed or packaged.
- The MCP Node REPL / Computer Use plugin failure is external testing infrastructure, explicitly identified by the user. It is NOT included in the Zeron bug count and is not being modified.
