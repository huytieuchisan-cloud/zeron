# Windows feature coverage

**Updated with final candidate verification results. This is an evidence-backed audit/acceptance matrix distinguishing verified automated/native probe coverage from unexercised live-account/hardware surfaces.** Baseline: official Zeron 0.2.119 at `dd0c36fa3ec1e269a630562179e655b1ed26f0a0`. Its executable hash matches the user's installed copy. The original installation, provider-owned credentials and existing sessions are preserved.

User decision: retain GPUI if verified targeted fixes work; a Tauri v2 replacement remains conditional, not waived if significant framework problems remain. Tauri itself documents the same legacy Acrylic movement limitation, so a framework substitution alone is not a proven remedy.
